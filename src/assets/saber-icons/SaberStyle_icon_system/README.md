# SaberStyle — sistema de iconos

**AICO · 112 iconos · SVG vectorial + PNG transparente**

Todos los SVG usan un `viewBox` de 24×24, geometría blanca pura (`#FFFFFF`), trazos redondeados de 1.8 unidades y fondo realmente transparente. Las variantes funcionales repetidas (p. ej., sonido activo, audio de accesibilidad y escucha del asistente) se conservan porque representan controles distintos y llevan detalles diferenciales.

## Integración en Ionic / Angular

Copia las diez carpetas de categoría bajo `src/assets/icons/`. Ejemplo: `<img src="assets/icons/navigation/home.svg" alt="" aria-hidden="true">`. Si el icono es informativo, define un `alt` descriptivo; para decoración junto a una etiqueta visible, usa `alt=""`. Los SVG están preparados para fondos oscuros/morados/azules y no incluyen fondos.
