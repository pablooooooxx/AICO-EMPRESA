# SaberStyle — Crear juegos: sistema de iconos

**30 iconos · SVG editable + PNG transparente de 256 × 256 px**

Familia vectorial de trazo blanco puro (`#FFFFFF`), cuadrícula `24 × 24`, trazo uniforme de 1.8 unidades con extremos y uniones redondeados. No se incrusta ningún fondo en los recursos individuales. Los símbolos y sus marcos funcionales forman parte del pictograma; no hay etiquetas ni numeración en los SVG.

## Integración con Ionic / Angular

Copia las tres carpetas en `src/assets/icons/game-creation/`. Ejemplo: `<img src="assets/icons/game-creation/create-games/quiz.svg" alt="" aria-hidden="true">`. Para iconos informativos, usa texto alternativo descriptivo; para iconos decorativos junto a una etiqueta visible, conserva `alt=""`.

## create-games/

01. **Quiz** — `quiz` — Hoja de quiz con pregunta y opción seleccionada.
02. **Verdadero o falso** — `true-false` — Dos opciones con marca y rechazo claramente distintos.
03. **Pregunta abierta** — `open-question` — Bocadillo abierto con línea de respuesta.
04. **Ruleta aleatoria** — `random-wheel` — Ruleta seccionada con puntero superior.
05. **Sopa de letras** — `word-search` — Cuadrícula con recorrido de búsqueda resaltado.
06. **Completar la palabra** — `complete-word` — Fragmento de palabra con un espacio vacío.
07. **Unir parejas** — `matching-pairs` — Dos columnas de elementos unidos por correspondencias.
08. **Ordenar secuencias** — `sequence-ordering` — Pasos enlazados en una secuencia vertical reordenable.
09. **Memoria** — `memory` — Tarjetas emparejables con símbolo común.
10. **Crucigrama** — `crossword` — Cuadrícula de crucigrama con entradas cruzadas.
11. **Adivina la imagen** — `guess-image` — Imagen con lupa para identificar el objeto.
12. **Desafío relámpago** — `lightning-challenge` — Rayo de rapidez y desafío.
13. **Clasificar** — `classify` — Elementos encaminados hacia categorías distintas.
14. **Tarjetas de estudio** — `flashcards` — Tarjetas superpuestas con señal de estudio.
15. **Laberinto de preguntas** — `question-maze` — Recorrido de laberinto con destino interrogativo.
16. **Reto por niveles** — `level-challenge` — Escalones ascendentes con bandera de meta.

## publishing/

17. **Jugar en vivo** — `live-game` — Antena de transmisión con ondas de emisión.
18. **Guardar en la nube** — `save-to-cloud` — Nube con flecha de subida.
19. **Asignar para después** — `schedule-assignment` — Calendario con reloj para programar una actividad.
20. **Guardar como borrador** — `save-draft` — Símbolo de guardado tipo disquete.
21. **Compartir juego** — `share-game` — Tres nodos conectados.
22. **Jugar en grupo** — `group-play` — Siluetas de participantes en grupo.
23. **Publicar actividad** — `publish-activity` — Documento con símbolo de publicación.
24. **Copiar código o enlace** — `copy-code-link` — Dos páginas superpuestas que representan una copia.

## editing/

25. **Añadir pregunta** — `add-question` — Signo más junto a una tarjeta de pregunta.
26. **Editar pregunta** — `edit-question` — Lápiz junto a un documento de pregunta.
27. **Eliminar pregunta** — `delete-question` — Papelera con tapa para quitar una pregunta.
28. **Reordenar preguntas** — `reorder-questions` — Flechas verticales en sentidos opuestos.
29. **Vista previa** — `preview` — Ojo para previsualizar el juego.
30. **Configurar juego** — `game-settings` — Engranaje para configurar el juego.
